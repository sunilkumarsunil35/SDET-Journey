# SDET Journey

Java and DSA practice on the way to becoming an SDET.

## Programs

| Program | What it does |
|---|---|
| [EvenOrOdd](Logic/Basic/EvenOrOdd.java) | Checks even or odd with the modulus operator |
| [EvenOrOddBitwise](Logic/Basic/EvenOrOddBitwise.java) | Checks even or odd with bitwise AND |
| [MultiplicationTable](Logic/Basic/MultiplicationTable.java) | Prints a multiplication table with a `for` loop |
| [MultiplicationTableRecursive](Logic/Basic/MultiplicationTableRecursive.java) | Prints a multiplication table with a `while` loop |
| [SumOfFirstNNumbers](Logic/Basic/SumOfFirstNNumbers.java) | Sum of the first n natural numbers |
| [SumOfFirstNSquareNumbers](Logic/Basic/SumOfFirstNSquareNumbers.java) | Sum of the squares of the first n natural numbers |

## Run a program

```sh
cd Logic/Basic
javac EvenOrOdd.java
java EvenOrOdd
```
